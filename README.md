# Rahma Code Agent

وكيل برمجة محلي لنظام Windows بواجهة عربية، وحلقة أدوات فعلية تعمل على مشروع يختاره المستخدم.

## التشغيل

```powershell
npm install
npm run dev
```

التحقق الكامل:

```powershell
npm run check
```

إنشاء نسخة Windows محمولة:

```powershell
npm run package:win
```

## التطوير والتحديث الفوري

لا حاجة لإعادة البناء يدويًا أثناء العمل على الكود؛ شغّل `npm run dev` مرة واحدة ويبقى التطبيق مفتوحًا:

- تعديل `src/renderer/*` → تحديث فوري للواجهة (HMR) دون إعادة تشغيل التطبيق.
- تعديل `src/main/*` أو `src/preload/*` → إعادة بناء وإعادة تشغيل تلقائية للتطبيق بأحدث الكود.
- تعديل `tests/*` → شغّل `npm test` مباشرة (سريع) دون إعادة تشغيل.
- أعد تشغيل `npm run dev` يدويًا فقط عند تغيير `package.json` أو إضافة اعتماديات جديدة.
- `npm run check` (البناء الكامل) مطلوب فقط قبل الحزم/الإصدار، لا أثناء التطوير اليومي.

## القدرات

- حلقة وكيل حتى 30 جولة و30 دقيقة، مع إلغاء فعلي ومهلة لاتصالات المزود.
- قراءة ملفات مرقمة مع `totalLines` ونطاق الأسطر، وأداة مستقلة لعد الأسطر.
- بحث أسماء بأسلوب glob وبحث محتوى يعيد الملف والسطر والعمود.
- كتابة وتعديل ذريان، ورفض التعديل عند وجود أكثر من تطابق.
- PowerShell محدود الزمن والمخرجات؛ يطلب موافقة في Ask وينفذ مباشرة في Full.
- بحث ويب عبر DuckDuckGo HTML وجلب صفحات HTTPS عامة، مع منع localhost والعناوين الخاصة وحد للمحتوى.
- أدوات Git مخصصة للحالة والفرق والسجل وcommit وrevert.
- وضعي Build وPlan، ونمطي Ask وFull. يطلب Ask الموافقة للعمليات المعدلة والحساسة، بينما ينفذ Full جميع الأدوات دون نوافذ موافقة.
- حفظ الجلسات والرسائل والملخصات وسجل النشاط في SQLite.
- خيار "إنشاء مستودع Git" عند فتح مشروع جديد (اختياري): ينشئ مستودعًا مع `.gitignore` يستثني مجلدات البناء، ويحفظ كل تعديل (كتابة/تعديل/حذف/نقل...) في commit تلقائي داخل الجلسة.
- حفظ استخدام المزود الفعلي والتقدير التقريبي لكل طلب وعرضه في الجلسة.
- استعادة tool calls المنقطعة دون إعادة تشغيل آثار جانبية محتملة.
- دعم صيغ Chat Completions وResponses وAnthropic Messages عبر OpenCode Go.
- دعم خوادم MCP عبر ملف `.mcp.json` داخل مساحة العمل؛ يطلب Ask الموافقة قبل التشغيل والاستدعاء، ويتجاوز Full جميع الموافقات.

## الأمان

- كل IPC يتحقق من مصدر النافذة ومدخلاته عبر Zod.
- لا يحصل Renderer على Node.js أو وصول مباشر للطرفية.
- مفتاح API مشفر عبر Windows DPAPI ولا يعاد إلى Renderer بعد حفظه.
- عمليات الملفات مرتبطة بمساحة عمل الجلسة وتتحقق من canonical paths وjunctions.
- الطرفية وخوادم MCP ليست sandbox كاملًا على مستوى Windows؛ وضع Full يشغلهما مباشرة باختيار المستخدم.
- الروابط الخارجية وصفحات الويب مقيدة بـHTTPS العامة، وتحتاج صفحات الويب موافقة في Ask فقط.
- معاينات الكتابة والتعديل تعرض Diff محدودًا قبل الموافقة، وتتحقق من أن الملف لم يتغير أثناء الانتظار.

## حدود الإصدار

- OpenCode Go هو المزود الحالي.
- لاستخدام MCP أنشئ `.mcp.json` في جذر المشروع، مثل:

  ```json
  {
    "mcpServers": {
      "filesystem": {
        "command": "npx",
        "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\work"]
      }
    }
  }
  ```

  خوادم MCP برامج خارجية بصلاحيات نظام التشغيل؛ لا تضف خادمًا لا تثق به.
- النسخة المحمولة محلية وغير موقعة رقميًا ما لم تُضف شهادة توقيع إلى عملية الإصدار.
- لا ينبغي توزيع نسخة غير موقعة على نطاق عام قبل إعداد code signing وقناة تحديث موثوقة.

هذا مشروع مستقل غير تابع لفريق OpenCode.
